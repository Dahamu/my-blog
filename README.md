# My blog (Next.js + Tailwind)

Put it online with GitHub Pages, no installs needed:

1. Create a new public repository on GitHub.
2. Upload everything in this folder to it (including the hidden .github folder).
3. Repo Settings > Pages > Source: GitHub Actions.
4. Open the Actions tab and wait for the green tick. Your site is at
   https://dahamu.github.io/my-blog/

To add a post to the public site: put a .md file in the content folder
(use "Download .md" in the editor at /admin/editor/).
